# Contributing to the homepage

Edit website components, layout, and documentation here. Change icon implementation/API in the Svelte repository; change artwork/motion recipes in core. Update the website's pinned adapter with `pnpm sync:svelte ../svelte`, rather than copying component source into the website.

Run `pnpm verify` and review desktop/mobile screenshots. Keep English interface text, the white/black/indigo palette, keyboard-accessible controls, and reduced-motion behavior. The design direction remains under review. Contributions to original code and artwork are submitted under the project’s [MIT license](LICENSE).
