# Contributing to the homepage

Edit website components, public gallery, layout and website documentation here. Original artwork belongs in core; adapter behavior belongs in Svelte. The shared construction reference is [Core ICON_RULES.md](../core/ICON_RULES.md).

The website consumes the exact published `@squircle-icons/svelte` version recorded in its manifest, lockfile and registry provenance. Keep these records and generated public catalogs consistent. Source sync is available only when intentionally previewing an unreleased public-package change; it is not an icon-review workflow.

Keep review applications, draft artifacts and experimental morph routes outside this website. Do not copy icon implementation paths into website components. Run `pnpm verify` and review desktop/mobile screenshots. Preserve English UI text, keyboard access, reduced motion and the established theme. Code/artwork contributions follow the project’s [MIT license](LICENSE).
